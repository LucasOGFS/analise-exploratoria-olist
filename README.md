# Análise Exploratória de Dados — E-commerce Brasileiro (Olist)

## Sobre o projeto

Este projeto tem como objetivo realizar uma análise exploratória de dados (EDA) utilizando Python, a partir do conjunto de dados público disponibilizado pela Olist, uma empresa brasileira de tecnologia voltada ao comércio eletrônico.

O objetivo é investigar informações relacionadas a vendas, clientes, produtos, pagamentos, logística e satisfação dos consumidores, identificando padrões e oportunidades de melhoria para o negócio.

## Objetivos

- Analisar o comportamento das vendas ao longo do tempo.
- Identificar produtos e categorias com melhor desempenho.
- Investigar o perfil geográfico dos consumidores.
- Analisar os métodos de pagamento utilizados.
- Avaliar a eficiência logística e os atrasos nas entregas.
- Investigar a satisfação dos clientes.
- Identificar padrões e relações entre as variáveis.
